Restart Python clears variables and files while keeping edited code. Running the second cell immediately after a restart raises `NameError`; run the first cell again to restore the list. Run all follows article order and stops at the first error. Earlier edits mark later results as needing another execution; dependencies are not recomputed automatically.

Reset code restores that cell's original source and clears its output. It keeps the current variables; use Restart Python to clear the environment.

The notebook is an opt-in mode of the existing CodePlayground and Python worker. Ordinary playgrounds remain independent. Each notebook allows one running cell at a time; loading packages has its own deadline, and each cell has the existing active-execution limit. Waiting for input pauses that cell's timer. Stop terminates the worker and clears the shared environment. Navigation also disposes it.

The final expression and `display()` produce text; Matplotlib produces PNGs. DataFrames and model summaries keep their readable text representations. HTML objects are converted to text, and arbitrary HTML or notebook widgets are not rendered. Saving a notebook downloads the current code as `.ipynb` without claiming that previous outputs have been rerun. Edits stay in the current page unless downloaded.
