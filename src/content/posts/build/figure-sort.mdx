Both figures sort the same sixteen values by replaying comparisons and swaps from an actual algorithm trace. The current pair uses the accent colour, and settled bars use stronger ink. Each comparison takes the same time in both figures, so an earlier finish reflects less work.

## Bubble sort

Compare adjacent bars and move the larger value to the right. Each pass settles the largest remaining bar at the end.

## Quicksort

Choose the final bar of a range as its pivot. Move smaller values ahead of it, place the pivot in its final position, and recursively partition the ranges on either side.
