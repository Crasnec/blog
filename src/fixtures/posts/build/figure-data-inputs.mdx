## Negative and positive values

Signed data needs an axis that represents its full range, including a visible zero baseline. The line and distribution below share measurements on both sides of zero. Neither requires shifting the observations into a positive range before drawing.

## Constant data

Equal observations still form a valid sample. An automatic axis must give them a nonzero display range instead of dividing by a zero span. A uniform colour field in the matrix means equal values, while the sorting trace still records comparisons of tied elements.

## Real key names

The hash-ring input is an array of actual strings. Their hashes determine ownership and movement when a server is added; changing a label is therefore a change to the workload, not merely decoration.

## An unreachable goal

Search can finish without finding a route. Once every reachable cell has been explored, the figure preserves a no-path outcome rather than drawing an invented connection or running indefinitely.

<UnreachableMaze />

To reuse a figure, replace its data at the TSX boundary. For example, a signed line needs no special renderer:

```tsx
import { Line } from "#src/components/figures/index.tsx";

export default function Deviations() {
  return <Line props={{
    series: [{ label: "Deviation", values: [-3, 0, 2, -1, 4] }],
    unit: "Difference from baseline",
  }} caption="Measurements cross the baseline in both directions." />;
}
```
