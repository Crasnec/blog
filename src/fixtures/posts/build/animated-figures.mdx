Place a `<Figure>` in a post to animate it when it enters the viewport. It follows the site's theme, offers replay after finishing, and holds its final frame for readers who prefer reduced motion.

For category comparisons, parts of a whole and filled time series, see [basic charts](/posts/build/basic-charts/): bars, pies, donuts and areas.

To assemble a diagram without drawing code, start with [the scene kit](/posts/build/scene-kit/): a visual catalog, automatic layouts and checked animation steps.

## Time series: line

The line draws from left to right, with its current value following the pen. A `notes` annotation appears when the pen reaches its position.

## Distributions: distribution

Samples fall into bins one at a time. Side-by-side groups can reveal different tails even when their means are similar. The upper five percent use the accent colour.

<LatencyDistribution />

## Request flow: flow

Requests move along arrows between boxes. An edge's `drop` value determines the fraction that fail at its destination.

<ServiceFlow />

## Post-specific TSX: checkout queues

Arrival times, service durations, server count and queue policies are inputs to the reusable `queue` kind. `_figures/CheckoutComparison.tsx` supplies this story's customer workload and wording; MDX imports that composition. The same queue figure can represent worker pools or service desks.

<CheckoutComparison registers={3} customers={12} />

```mdx
import CheckoutComparison from "./_figures/CheckoutComparison.tsx";

<CheckoutComparison registers={3} customers={12} />
```

## Post-specific TSX: several views of one sample

`_figures/LatencyComparison.tsx` passes one sample to an ECDF and a boxplot. TSX owns the post's data and composition, while shared figures handle computation and drawing. Replace `groups` and `unit` to use another sample.

<LatencyComparison />

## Post-specific TSX: a bespoke SVG

A drawing that does not fit an existing kind can use SVG directly inside TSX. `_figures/NormalCoverage.tsx` computes a normal density and cumulative probability, then shades the central interval. `SvgFigure` supplies the accessible description and caption.

<NormalCoverage deviations={1.96} />
